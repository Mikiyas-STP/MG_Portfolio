## 📦 Installation

1. **Clone the repo**
    ```bash
    git clone https://github.com/Mikiyas-STP/MG_Portfolio.git
    ```

2. **Navigate into project**
    ```bash
    cd MG_Portfolio
    ```

3. **Install dependencies**
    ```bash
    npm install
    ```

4. **Run the development server**
    ```bash
    npm run dev
    ```

---

## ⚙️ Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start local dev server |
| `npm run build` | Create production build |
| `npm run preview` | Preview production build |

## 📌 Deployment

To deploy this portfolio:

1. Create a production build:
    ```bash
    npm run build
    ```

2. Deploy with a service like **Netlify**, **Vercel**, or **GitHub Pages**.
